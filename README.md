# Meus Workflows do n8n

Repositório dedicado ao armazenamento e versionamento dos meus fluxos de automação desenvolvidos no n8n.

## Workflows Disponíveis

* **[My workflow (1).json](https://github.com/nertan55/n8n-workflows/blob/main/My%20workflow%20(1).json):** Assistente de IA integrado ao Google Gemini e Gmail para automação e envio de mensagens inteligentes.
* **[My workflow 2.json](https://github.com/nertan55/n8n-workflows/blob/main/My%20workflow%202.json):** Automação acionada por formulário que consome dados da API do GitHub via requisição HTTP e processa o resultado com código JavaScript.
* **[My workflow 3.json](https://github.com/nertan55/n8n-workflows/blob/main/My%20workflow%203.json):** Automação acionada por formulário que processa dados com JavaScript e registra as informações diretamente em uma planilha do Google Sheets.
